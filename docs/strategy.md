# trend-breakout-v1 规则

机器读取的策略配置位于 [`config/strategy.json`](../config/strategy.json)；下面说明其当前默认取值。

## 指标

所有首版指标都基于当前数据版本所定义的同一价格口径。演示库使用未复权合成日线。

- `H20(t)`：此前 20 根有效日线的最高价最大值，不包含 `t` 日。
- `L10(t)`：此前 10 根有效日线的最低价最小值，不包含 `t` 日。
- `MA21(t)`、`MA55(t)`：截至 `t` 日收盘的 21 / 55 根简单移动平均。
- `平均成交额20(t)`：此前 20 根已完成日线成交额的平均值。演示成交额为收盘价乘成交量的估算值，字段不称为供应商成交额。
- 至少有 75 根历史日线用于策略预热；不足时不产生可回放结果。

## 事件与模拟

- 无模拟仓位、无待执行入场：若 `close(t) > H20(t)` 且 `MA21(t) > MA55(t)`，记录“突破观察”。
- 有模拟仓位：若 `close(t) < L10(t)` 或 `MA21(t) < MA55(t)`，记录“退出观察”。
- 条件相等不会触发事件；同一持仓不会重复入场，也不加仓、不做空。
- `t` 日收盘后才确认的信号，最早在下一交易日开盘模拟执行；未到下一开盘的事件保持待执行。没有有效开盘价时记录跳过原因，不虚构成交。
- 默认每边佣金 5 bps、滑点 5 bps；均为可调假设，不代表任何券商的实际费用。回放按单标的满仓复利计算，不将独立证券结果相加称为组合收益。
- 资金曲线按每日收盘估值计算；公司行动缺少处理时，受影响区间的模拟会被阻断。

## 回放和版本

- API 的 `as_of` 会先限制可见K线，再计算指标；信号、排名和指标均不可使用截止日后的数据。
- 每个信号与快照保存规则版本、数据修订版本和时间戳。已发布快照不覆写；更换规则或数据时生成新记录。
- 演示证券没有公司行动；真实数据接入前，拆股、分红、停牌、退市和证券代码映射的覆盖不足必须作为阻断条件，而不是自动补值。
